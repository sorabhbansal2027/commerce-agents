Salesforce Integration Architecture

SalesforceOMSBackend
Implements both StorefrontBackend + MerchantBackend in one class
Auth: OAuth2 client_credentials → token cache → Bearer header
_soql() — SOQL queries _b2b_request() — B2B REST API _gap_fill_recent_products() _add_to_cart_direct() _group_variants()
SF Objects touched: Product2 · PricebookEntry · WebCart · CartItem · CartDeliveryGroup · OrderSummary · Quote · QuoteLineItem · ProcessInstanceWorkitem · Asset · Contract
Product Catalog Loading
1. B2B Commerce Products API (primary — indexed products)
2. Gap-fill: SOQL subqueries on ProductCategoryProduct + CommerceEntitlementProduct, LAST_N_DAYS:30, UnitPrice > 0
3. Fallback: PricebookEntry SOQL if B2B API unavailable
4. _group_variants() creates FAMILY- synthetic IDs
Add-to-Cart Flow
1. POST /commerce/webstores/{id}/carts/{cartId}/cart-items
2. If 404 (not in B2B index) → _add_to_cart_direct()
→ POST /sobjects/CartItem with SalesPrice from product cache
Quote Approval Flow
Shopping agent submits → Salesforce Approval Process (ProcessInstanceWorkitem) → Merchant agent approves/rejects via /process/approvals/ REST API
