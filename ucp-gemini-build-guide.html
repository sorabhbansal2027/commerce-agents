What is UCP?

Universal Commerce Protocol — RFC 8615 manifest + REST endpoints
💡

The core idea: Publish a manifest at GET /.well-known/ucp describing your store's capabilities. Any UCP-aware AI agent (Gemini, Claude, or any LLM) fetches it at startup, reads which endpoints exist, and builds its own tool declarations dynamically — no store-specific code on the agent side.

📄 Manifest

Served at /.well-known/ucp. Declares capabilities (search, cart, checkout), endpoints, payment handlers, and transport options.

🔧 Agent Auto-Discovery

Gemini fetches the manifest once at startup. GeminiUCPAgent._build_tools() turns each capability into a FunctionDeclaration.

🔄 Agentic Loop

Gemini decides which UCP endpoints to call. The agent executes them as HTTP requests and feeds results back. Repeats until Gemini stops calling functions.

1

Publish the UCP Manifest

examples/demo_common/ucp.py · build_ucp_manifest()

The manifest is the contract. Mount it at GET /.well-known/ucp (domain root per RFC 8615). Gemini reads it once and never needs updating unless your capabilities change.

Python examples/demo_common/ucp.py — build_ucp_manifest() 
def build_ucp_manifest(backend, base_url: str) -> dict:
    return {
        "schema_version": "1.0",
        "business": {
            "name": backend.store_name,
            "description": "B2B commerce storefront with product search and checkout.",
        },
        "capabilities": {
            "product_discovery": {
                "supported": True,
                "endpoints": {
                    "search": f"{base_url}/ucp/products",
                    "detail": f"{base_url}/ucp/products/{product_id}",
                },
                "features": ["full_text_search", "category_filter", "price_range_filter"],
            },
            "checkout": {
                "supported": True,
                "endpoints": {
                    "create_session": f"{base_url}/ucp/checkout-sessions",
                },
                "note": "Sessions are pending — no charge is made here.",
            },
        },
        "payment_handlers": [
            {"id": "credit_card", "name": "Credit Card"},
            {"id": "purchase_order", "name": "Purchase Order (B2B)"},
        ],
        "transport": {
            "rest": {"base_url": base_url, "auth": "UCP-Agent"},
            "mcp": {"description": "Richer Claude agent available over MCP."},
        },
        "agent_hints": "Prefer MCP for complex journeys; REST for single-turn lookups.",
    }
⚡

Key field: capabilities — Gemini reads product_discovery.supported and checkout.supported to decide which tools to build. Add cart_management.supported: true if you expose cart endpoints. Add features arrays to make tool descriptions more precise.

@router.get("/ucp/products")
async def ucp_search_products(
    q: str = "",
    category: str | None = None,
    min_price: float | None = None,
    max_price: float | None = None,
    limit: int = 10,
) -> Response:
    results = [
        _listing_to_ucp(p)                     # normalize to UCP schema
        for p in backend.products.values()
        if _matches(p, q, category, min_price, max_price)
    ][:limit]
    return Response(json.dumps({"products": results, "total": len(results)}))

# Each product must have: product_id, title, price, currency, in_stock
def _listing_to_ucp(p) -> dict:
    return {
        "product_id": p.product_id,
        "title":      p.title,
        "price":      p.price,
        "currency":   p.currency,
        "in_stock":   p.in_stock,
        # optional extras Gemini will use if present:
        "image_url":  p.image_url,
        "category":   p.category,
        "brand":      p.brand,
    }

Build the GeminiUCPAgent

examples/demo_common/gemini_ucp_agent.py

The agent class has two jobs: (1) fetch the manifest and auto-build Gemini FunctionDeclaration objects, and (2) run the agentic loop — execute HTTP calls for each function Gemini requests, feed results back, repeat until Gemini stops calling functions.

Python examples/demo_common/gemini_ucp_agent.py — __init__ and manifest discovery 
from google import genai
from google.genai import types as gtypes

class GeminiUCPAgent:
    def __init__(self, ucp_base: str, *, model="gemini-3.6-flash", api_key=None):
        self.base = ucp_base.rstrip("/")
        self._http = httpx.Client(timeout=15.0)
        self._client = genai.Client(api_key=api_key or os.environ["GEMINI_API_KEY"])

        # ① Fetch manifest from storefront
        resp = self._http.get(f"{self.base}/.well-known/ucp")
        self.manifest = resp.json()

        # ② Auto-build tool declarations from manifest capabilities
        self._tools = self._build_tools()

        # ③ Build system prompt from manifest business info
        self._config = gtypes.GenerateContentConfig(
            tools=self._tools,
            system_instruction=self._system_prompt(),
        )
        self._contents: list[gtypes.Content] = []   # stateful history
Python examples/demo_common/gemini_ucp_agent.py — _build_tools() from manifest 
def _build_tools(self) -> list[gtypes.Tool]:
    caps = self.manifest.get("capabilities", {})

    # ── Product search tool ───────────────────────────────────────────
    if caps.get("product_discovery", {}).get("supported"):
        features = caps["product_discovery"].get("features", [])
        # Tool description is built from manifest features — no hardcoding
        search_desc = "Search the catalog."
        if "price_range_filter" in features:
            search_desc += " Supports price range filter."

    # ── Checkout tool ────────────────────────────────────────────────
    if caps.get("checkout", {}).get("supported"):
        payment_ids = [
            p["id"] for p in self.manifest.get("payment_handlers", [])
        ]
        # Payment options come from manifest — works with any store
        ph_desc = f"Options: {', '.join(payment_ids)}."

    # Returns list[gtypes.Tool] with FunctionDeclaration objects
    # Gemini uses these to decide when/how to call each endpoint

Python examples/demo_common/gemini_ucp_agent.py — send() agentic loop 
def send(self, message: str) -> str:
    self._contents.append(
        gtypes.Content(role="user", parts=[gtypes.Part(text=message)])
    )

    while True:                                         # ← agentic loop
        response = self._client.models.generate_content(
            model=self._model_name,
            contents=self._contents,
            config=self._config,
        )
        candidate = response.candidates[0]
        self._contents.append(candidate.content)    # keep history

        fn_calls = [
            part.function_call
            for part in candidate.content.parts
            if part.function_call
        ]

        if not fn_calls:                              # ← done
            return "\n".join(p.text for p in candidate.content.parts if p.text)

        # Execute each function call and collect responses
        fn_resp_parts = []
        for fc in fn_calls:
            result = self._call_ucp(fc.name, dict(fc.args))
            fn_resp_parts.append(gtypes.Part(
                function_response=gtypes.FunctionResponse(
                    name=fc.name, response={"result": result}
                )
            ))

        # google-genai requires role="user" for function_response parts
        self._contents.append(
            gtypes.Content(role="user", parts=fn_resp_parts)
        )
⚠️

google-genai quirk: Function response parts must use role="user" in the contents list. This differs from how Anthropic's Messages API handles tool results. The loop above is correct for google-genai 1.x.

Extend with TrackedAgent (Cart + Orders)

scripts/gemini_web_server.py — TrackedAgent

The base GeminiUCPAgent only knows about UCP endpoints. For a full shopping app you need server-side cart state, order placement, and frontend signals. TrackedAgent subclasses it and injects extra tools.

🛒 Server-side cart (self.cart)

A persistent Python list that survives across chat turns in the same process. add_to_cart appends to it; place_b2b_order clears it after a successful order.

📡 Frontend signals (last_tool_calls)

Each HTTP request resets last_tool_calls = []. As tools execute, they append {"tool": name, "args": ...}. The /api/chat response returns this list so React can sync state.

💳 cart_additions

Only the items added this turn. The React frontend iterates this array to display newly added products — separate from the full persistent cart.

📋 checkout_session

Set to the order result on success (status: "placed"). The React frontend reads checkout_session.status === 'placed' to clear the cart UI after order placement.

Python scripts/gemini_web_server.py — TrackedAgent (condensed) 
class TrackedAgent(GeminiUCPAgent):
    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self.cart: list[dict] = []             # persistent across turns
        self.cart_additions: list[dict] = []    # this-turn additions for React
        self.last_tool_calls: list[dict] = []   # all tool calls this turn
        self.checkout_session: dict | None = None

        # Inject extra FunctionDeclarations beyond what manifest provides
        self._tools.append(gtypes.Tool(function_declarations=[
            add_to_cart_decl,     # adds product to self.cart
            place_b2b_order_decl, # places Salesforce order, clears cart
            save_quote_decl,      # saves cart as draft quote
            load_quote_decl,      # loads quote items into cart
        ]))

    async def execute_tool(self, fn_name: str, args: dict) -> dict:
        if fn_name == "add_to_cart":
            self.last_tool_calls.append({"tool": fn_name, "args": args})
            product = fetch_product(args["product_id"])
            self.cart.append({"product": product, "quantity": args.get("quantity", 1)})
            self.cart_additions.append({"product": product, "quantity": args.get("quantity", 1)})
            return {"ok": True, "cart_count": len(self.cart)}

        if fn_name == "place_b2b_order":
            self.last_tool_calls.append({"tool": fn_name, "args": args})
            result = await place_salesforce_order(self.cart, args)
            self.checkout_session = result   # status: "placed"
            self.cart.clear()                  # cart closed after order
            return result

Wire Up the FastAPI + React Server

scripts/gemini_web_server.py — API endpoints

POST /api/chat

Resets last_tool_calls and cart_additions, calls agent.send(message), returns reply + tool_calls + cart_additions + checkout_session.

POST /api/cart

Shortcut for "add to cart" via the chat interface without going through a full conversational turn. Appends the item and returns a brief acknowledgement.

GET /api/active-cart

Returns the current agent.cart list. React fetches this on login to pre-populate the cart sidebar from the server's in-memory state.

POST /api/reset

Clears conversation history (agent.reset()), cart, and checkout session. "New conversation" button in the UI calls this.

Python scripts/gemini_web_server.py — /api/chat 
@app.post("/api/chat")
async def chat(body: ChatBody):
    # Reset per-turn state
    agent.last_tool_calls = []
    agent.cart_additions  = []
    agent.checkout_session = None

    reply = await agent.send(body.message)   # runs the agentic loop

    return {
        "reply":            reply,
        "tool_calls":       agent.last_tool_calls,   # React: detect place_b2b_order
        "cart_additions":  agent.cart_additions,     # React: add new items to sidebar
        "checkout_session": agent.checkout_session,   # React: status === 'placed'
        "products":         agent.last_products,       # React: render product cards
    }

const data = await fetch('/api/chat', { method: 'POST', body: ... }).json()

// Detect order placement — two independent signals
const orderPlaced =
  (data.tool_calls ?? []).some(tc =>
    tc.tool === 'place_b2b_order' || tc.tool === 'place_order'
  ) || data.checkout_session?.status === 'placed'

if (orderPlaced) {
  setCartItems([])           // clear sidebar
  setAddedIds(new Set())
}

// Sync new items from cart_additions
if (!orderPlaced && data.cart_additions?.length) {
  for (const { product, quantity } of data.cart_additions) {
    setCartItems(prev => [...prev, { product, quantity }])
  }
}

    Product search endpoint — GET /ucp/products?q=&category=&min_price=&max_price=&limit=; response has products[].{product_id, title, price, currency, in_stock}
