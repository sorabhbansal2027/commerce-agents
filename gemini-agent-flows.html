Two Flows Traced

🔍
Flow 1 — Product Discovery
"Show me laptops under $1,200"
1
User
Types message in chat input box
2
React Frontend
Sends HTTP POST to backend
POST /api/chat {"message": "Show me laptops under $1,200"}
3
FastAPI Server
Forwards to Gemini API with the UCP tool definitions already loaded (from GET /.well-known/ucp at startup)
4
Gemini Model
Decides to call a tool. Returns:
FunctionCall: search_products(query="laptop", max_price=1200)
5
UCP Endpoint (same container)
FastAPI calls its own UCP layer
GET /ucp/products?q=laptop&max_price=1200
→ queries Salesforce B2B via REST / SOQL
6
FastAPI Server
Feeds product list back to Gemini as a FunctionResponse, then loops
role="user" → FunctionResponse: [ProBook, EliteBook, ...]
7
Gemini Model
Generates natural language reply with product context — no more tool calls needed
8
React Frontend
Receives JSON response, renders chat reply + product-grid cards
{reply, products: [...], tool_calls: [...]}
🛒
Flow 2 — Add to Cart
"Add 2 ProBook to my cart"
1
User
Types message, OR clicks the Add to Cart button on a product card
2
React Frontend
Sends to backend — typed message uses /api/chat, button click uses /api/cart
POST /api/chat {"message": "Add 2 ProBook to my cart"}
3
FastAPI Server
Forwards to Gemini with conversation history (prior search results are in context)
4
Gemini Model
Identifies the ProBook from prior context. Returns:
FunctionCall: add_to_cart(product_id="P-001", quantity=2)
5
UCP Endpoint (same container)
FastAPI calls the checkout-sessions endpoint
POST /ucp/checkout-sessions {items: [{product_id, qty: 2}]}
6
TrackedAgent (in-memory)
Records the addition in self.cart and self.cart_additions — persists for the session lifetime
7
Gemini Model
Receives tool result, generates confirmation reply
8
React Frontend
Receives response, syncs cart sidebar from cart_additions field — shows ProBook × 2
{reply, cart_additions: [{product, quantity: 2}]}

  • Sends mcp/ui_ready on load

Flow A — Search results pushed to iframe
User
Types "Show me laptops" in chat input (left panel)
→
FastAPI + Gemini
Runs full UCP loop. Returns JSON with products:[...] array alongside the reply
→
Parent Page JS
Calls pushProducts(data.products) — sends product array to iframe via postMessage
{ products: [ {id, title, price, image_url}, … ] }
→
Product Grid iframe
Receives message, renders product cards with images, titles, prices, and an Add to Cart button on each
⚠️ If iframe hasn't loaded yet when reply arrives, products are queued in pendingProducts and pushed once mcp/ui_ready fires.
Flow B — Add to Cart clicked inside iframe
Product Grid iframe
User clicks Add to Cart. Iframe sends JSON-RPC call to parent window:
{ jsonrpc:"2.0", id:1, method:"mcp/call_tool", params:{ name:"add_to_cart", arguments:{product_id, quantity:1} } }
→
Parent Page JS
Listens via window.addEventListener("message"). Checks msg.method === "mcp/call_tool" and name === "add_to_cart", then calls backend
POST /api/cart {product_id, quantity}
→
FastAPI + Gemini
Gemini notified: "User added product_id to cart qty 1". Runs UCP loop → creates checkout session via POST /ucp/checkout-sessions
→
iframe ← parent
Parent responds to iframe with JSON-RPC result so the button state updates (no double-click):
{ jsonrpc:"2.0", id:1, result:{} }
JSON-RPC 2.0 Message Reference (postMessage protocol)
Direction method Payload Purpose
iframe → parent mcp/ui_ready — iframe has loaded; parent can now push products
iframe → parent mcp/call_tool {name:"add_to_cart", arguments:{product_id, quantity}} User clicked Add to Cart button in the grid
parent → iframe (products push) {products:[{id, title, price, image_url}]} Push search results to render in the product grid
parent → iframe (JSON-RPC result) {jsonrpc:"2.0", id, result:{}} Acknowledge tool call so iframe resets button state

Routes + tracks
Updates self.cart[] in memory. Records in self.cart_additions so React sidebar can sync. Then calls UCP.

④ Salesforce Auth — JWT Bearer (runs before every token-expired call)
OAuth JWT Bearer Flow
1
Sign JWT
Server signs a JWT with SF_PRIVATE_KEY. Claims: iss=SF_CLIENT_ID, sub=SF_USERNAME, aud=login.salesforce.com, 3-min expiry.
2
Exchange for access token
POST /services/oauth2/token
grant_type = urn:ietf:params:oauth:grant-type:jwt-bearer
3
Token stored in memory
Salesforce returns access_token + instance_url. Cached in the Python process. Refreshed on 401.
4
Every API call uses it
Header: Authorization: Bearer {access_token}. No user login required — server-to-server only.

How UCP and Gemini Coordinate

Moment Who acts What happens Layer
Server startup TrackedAgent Fetches GET /.well-known/ucp — reads the manifest to discover which capabilities (search, checkout) are available, then builds Gemini FunctionDeclaration objects automatically. Gemini never needs manual tool registration. UCP
Every turn FastAPI → Gemini The same tool definitions are sent on every request alongside the conversation history. Gemini decides whether to answer directly or call a tool — it is the single decision-maker. Gemini
Tool call returned FastAPI (agentic loop) If Gemini returns a FunctionCall, FastAPI executes the matching UCP HTTP endpoint, collects the result, and re-sends to Gemini as a FunctionResponse. The loop repeats until Gemini returns plain text. FastAPI UCP
UCP → Salesforce UCP layer The UCP endpoint translates the call into a Salesforce REST / SOQL query using the stored OAuth token. Gemini never talks to Salesforce directly — UCP is the only bridge. Salesforce
Cart state TrackedAgent self.cart is an in-memory Python list inside the running container. It survives across turns in a session but resets on deploy or container restart. The React cart sidebar mirrors it via cart_additions in the JSON response. FastAPI React
Reply to user FastAPI → React Once Gemini returns text (no more tool calls), FastAPI assembles a single JSON response with reply, products, tool_calls, cart_additions, and checkout_session. React renders it all in one update. React
