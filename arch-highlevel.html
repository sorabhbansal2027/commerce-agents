Reference Architecture

Architecture Overview

Access Channels

LWC
Lightning Web Components
Salesforce-embedded buyer chat panel and merchant portal with Quote Approvals tab. Apex controllers bridge to the AI backend over HTTPS.
Salesforce Users
NJS
Next.js Headless Storefront
Four vertical storefronts (Retail, Entertainment, Food, B2B) each with a buyer UI and merchant dashboard. Streaming AI assistant sidebar on every page.
Web Shoppers
UCP
Universal Commerce Protocol
Google open-standard REST endpoints for discovery, product search, and checkout. Any AI agent auto-discovers capabilities — no custom integration needed.
External AI Agents
MCP
MCP Apps — Claude + SEP-1865
Claude MCP server exposes tools plus a ui:// product-grid resource. Host renders an interactive iframe alongside chat; postMessage bridge for cart actions.
Claude Desktop Users
PLG
Claude Code Plugin
commerce-builder plugin with 6 developer skills and 4 commands: scaffold new agents, review flows, add skill templates, and author evaluation sets.
Developers

Key Capabilities

Protocol-agnostic

Generative UI
