SSE Event Types — /api/chat response stream
text_deltaCharacter stream of Claude's reply textdata: {"text": "..."}
cart_updateFires after add_to_cart succeeds; contains full cart statedata: {"cart": {"items":[...]}}
progressTool call in-progress indicatordata: {"message": "Searching..."}
tool_callTool invocation details (name + input)data: {"name": "search_products", ...}
uiCompleted generative UI block (products, comparison, plan…)data: {"component": "products", "payload":{...}}
ui_partialStreaming fragment of a UI block during generationdata: {"component": "...", ...}
suggestionsFollow-up prompt suggestions after turn endsdata: {"suggestions": ["...", ...]}
turn_completeTurn finished; includes stop_reason, usage, elapsed_msdata: {"stop_reason": "end_turn", ...}
errorAgent or tool error with messagedata: {"error": "..."}

Managed Agent Deploy Scripts
scripts/deploy_managed_agent.sh — Posts agent manifest to Managed Agents API
deploy_managed_agent.sh shopping-agent/managed-agents/shopping-agent Dry run — prints the /v1/agents request body
deploy_managed_agent.sh shopping-agent/managed-agents/shopping-agent --live Live deploy — uploads 5 skills, creates agent, prints agent ID
deploy_managed_agent.sh merchant-agent/managed-agents/merchant-agent Merchant agent dry run
deploy_managed_agent.sh merchant-agent/managed-agents/merchant-agent --live Merchant agent live deploy
