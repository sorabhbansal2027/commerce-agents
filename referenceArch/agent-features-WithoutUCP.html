1
Staged-Write Protocol
Staged-Write Protocol — All writes (price, listing, inventory, promotion) go through changes.py: propose → review → apply_change. The host UI must confirm before any mutation reaches Salesforce. Reads are unrestricted.

Commerce Builder Plugin

A Claude Code plugin that gives developers skills and commands to scaffold, extend, evaluate, and review commerce agents within their own repos.

6
Skills
4
Commands
Plugin Skills
🏗️
commerce-architecture
Design patterns for two-role agents: StorefrontBackend ABC, tool registry, fencing, memory, prompt assembly. Use when designing or reviewing the overall agent structure.
🖼️
commerce-ui-tools
PresentationExtension patterns: writing UI tools, validating tool outputs server-side, streaming ui/ui_partial SSE events, and registering new card types.
🛡️
commerce-trust-safety
Gates, fencing, and provenance rules: quantity caps, checkout charges-nothing contract, staged-write approval, third-party content fencing, merchant write safety.
⚡
commerce-prompt-caching
Static-vs-dynamic prompt design: breakpoint placement, fenced block structure, cache TTL mechanics, reducing per-turn token cost for multi-turn sessions.
📊
commerce-merchant-operations
Merchant-specific patterns: staged-write protocol, analysis delegate, changes.py, analysis.py, approval-gated writes, and how to extend the merchant backend.
🧪
commerce-evals
Writing evaluation harnesses: tool-call trace assertions, golden-path scripts, regression fixtures, and running the shared test suites in tests/ against a custom backend.
Slash Commands
🚀
/scaffold-commerce-agent
Generates the full directory structure for a new commerce agent vertical: backend stub, API server, storefront-web, merchant-web, data fixtures, and env templates. Accepts a vertical name and optional feature flags.
➕
/add-commerce-flow
Adds a new skill or tool category to an existing commerce agent: creates the skill SKILL.md, registers the tool in the tool registry, adds backend method stubs, and wires the presentation extension.
📐
/author-commerce-evals
Generates evaluation fixtures and golden-path test scripts for one or more tools or skills: produces pytest parametrize tables and trace-assertion helpers.
🔍
/review-commerce-agent
Audits an existing commerce agent implementation against the design rules in CLAUDE.md: checks fencing, provenance gates, static/dynamic prompt split, tool description quality, and eval coverage.
