Reference Architecture
Three layers work together: any AI agent discovers the store via UCP, Claude's MCP server adds rich tool access and interactive UI, and Gemini connects both through the same standard REST contract.
Gemini / UCP path
Claude / MCP path

⬡ UCP Flow — any AI agent

1
Agent fetches /.well-known/ucp → reads manifest
2
Auto-generates function declarations from capabilities block
3
Calls GET /ucp/products?q=…&max_price=…
4
Creates checkout session with confirmed items
5
No custom adapter — works with Gemini, GPT, any LLM

⬡ MCP Apps UI Flow — Claude host

1
User asks Claude to search products
2
Agent calls search_products_ui tool
3
Result includes _meta.ui.resourceUri: "ui://storefront/product-grid"
4
Host fetches resource, renders HTML iframe alongside chat
5
User clicks Add to Cart → postMessage → add_to_cart fires

examples/demo_common/ucp.py
UCP Router
5 FastAPI endpoints: manifest, product search, product detail, checkout session create/status. Mounted at app root — no prefix so /.well-known/ucp resolves correctly.
examples/demo_common/gemini_ucp_agent.py
GeminiUCPAgent
Fetches the UCP manifest at init. Auto-builds Gemini FunctionDeclaration objects from the capabilities block. Stateful multi-turn send() with agentic loop. Works against any UCP store.
shopping-agent/managed-agents/storefront-mcp-server/product_grid_ui.html
MCP Apps HTML
Self-contained product card grid. Receives products via postMessage. "Add to cart" fires mcp/call_tool back to host. Light/dark mode. Served at ui://storefront/product-grid.
shopping-agent/managed-agents/storefront-mcp-server/storefront_mcp_server.py
MCP Server
Registers the ui://storefront/product-grid resource and search_products_ui tool. Tool result includes _meta.ui.resourceUri — older hosts ignore it safely.
scripts/gemini_ucp_demo.py
Terminal Demo
4-turn canned shopping conversation or --interactive REPL. Prints manifest capabilities, tool names, and full Gemini responses. Runs with just a GEMINI_API_KEY.
scripts/gemini_mcp_ui_server.py
Split-screen Demo Server
FastAPI server on port 8099. Left panel: Gemini chat via UCP. Right panel: MCP Apps product-grid iframe. postMessage bridge connects both. POST /api/cart triggers Gemini checkout.
How to Demo — UCP + MCP Apps UI
Three demo scenarios from simplest (curl) to most impressive (live split-screen). Run them in this order for a leadership presentation.

1 UCP Discovery — "Any agent can find us"

30-second curl demo. Shows leadership that the storefront is already discoverable by any AI agent on the internet.
①

Fetch the capability manifest

Any UCP-aware agent starts here. This single call tells it everything about your storefront — no docs, no custom SDK.

curl https://diligent-flow-production-afd7.up.railway.app/.well-known/ucp | python3 -m json.tool
✓ Returns JSON with business name, 3 capabilities (product_discovery, cart_management, checkout), 2 payment handlers, REST + MCP transport URLs.
②

Search the product catalog (sessionless)

No login, no session token. Any agent can query the catalog immediately after reading the manifest.

curl "https://diligent-flow-production-afd7.up.railway.app/ucp/products?q=laptop&max_price=2000"
✓ Returns JSON array of 3 laptops — ProBook Ultra 13 ($949), ProBook Elite 15 ($1,299), ProBook Ruggedized ($1,799) — with product_id, price, in_stock, image_url.
③

Create a checkout session

Show that the entire journey from discovery to checkout initiation requires zero custom code on the agent side.

curl -X POST https://diligent-flow-production-afd7.up.railway.app/ucp/checkout-sessions \ -H "Content-Type: application/json" \ -d '{"line_items":[{"product_id":"01tDS00000KIpo9YAD","quantity":1}],"buyer":{"name":"Alex Rivera"}}'
✓ Returns checkout_session_id (ucp-xxxxx), status: "pending", line_items with prices, subtotal $949.00. No charge made.
💡 Leadership talking point: "This is the same API call Gemini, GPT, or our procurement bot would make — same schema, same response, zero custom glue."

2 Gemini × UCP — "Google's AI shops our catalog"

Terminal demo. Gemini auto-discovers the store, searches products, and creates a checkout session through a natural conversation.
①

Install the Gemini SDK (one-time)

pip install -r requirements.txt -r requirements-gemini.txt
②

Run the 4-turn canned demo

GEMINI_API_KEY=your-key python3 scripts/gemini_ucp_demo.py
✓ Prints: store name "Salesforce", tools auto-generated from manifest: search_products, get_product, create_checkout_session. Then 4 turns: catalog overview → 3 laptops → product detail → checkout confirmation.
③

Or: interactive REPL for live Q&A with leadership

GEMINI_API_KEY=your-key python3 scripts/gemini_ucp_demo.py --interactive
💡 Suggested prompts for leadership:
• "What networking equipment do you carry under $500?"
• "Compare your two cheapest laptops"
• "I need 5 workstations for a dev team, what do you recommend?"

3 Gemini + MCP Apps UI — Split-screen live demo

The flagship demo. Gemini chat on the left, interactive product grid on the right. Clicking "Add to cart" triggers a full checkout loop.
①

Start the demo server

pip install fastapi uvicorn # one-time GEMINI_API_KEY=your-key python3 scripts/gemini_mcp_ui_server.py
✓ Prints: "Gemini × UCP + MCP Apps UI Demo" · URL: http://localhost:8099 · Storefront: Railway URL
②

Open the browser demo

open http://localhost:8099
✓ Split screen: left panel shows "Gemini 3.6 Flash — UCP shopping agent", right panel shows "MCP Apps product grid · ui://storefront/product-grid" with "Waiting for product data…"
③

Type a search query

Type in the chat input and press Enter (or click Send).

show me laptops under $2000
✓ Left: Gemini responds listing 3 laptops with prices. Bottom bar shows: "→ search_products(q="laptop", max_price=2000)" Right: 3 product cards appear with images, prices, "Add to cart" buttons. The MCP Apps iframe updated via postMessage.
④

Click "Add to cart" in the product grid

Click any "Add to cart" button in the right panel. Watch both sides update simultaneously.

✓ Right: button turns green "Added ✓" (iframe got tool response via postMessage). Left: system message shows "Cart action: adding [product_id]…" then Gemini responds with full checkout confirmation — item, price, total, asks for name/email/payment method. Bottom bar: "→ get_product(product_id=…)"
💡 Leadership talking point: "The user never left the chat. The product grid is the MCP Apps standard — the same HTML the Claude MCP server serves. Gemini, Claude, any future agent host can render it."
⑤

Complete the checkout (optional)

In the chat input, reply to Gemini's confirmation prompt:

Yes, please proceed. My email is alex@company.com, pay by purchase order.
✓ Gemini calls create_checkout_session via UCP, returns checkout_session_id with full line items and total. No payment charged.
