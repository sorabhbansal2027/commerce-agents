Layer-by-Layer: What Exactly Changes

1
Salesforce B2B — Product Catalog HIGH EFFORT
All data lives here — most work is catalog migration, not code
Electronics fields (current)
  • Processor, RAM, Storage, Display size
  • Battery life, Connectivity (WiFi/BT)
  • Weight, Dimensions (laptop form factor)
  • Category: Laptops / Monitors / Accessories
  • Warranty: 1yr / 2yr / 3yr
Fragrance fields (new)
  • Scent family: Floral / Woody / Oriental / Citrus / Aquatic / Chypre
  • Concentration: EDT / EDP / Parfum / EDC / Body Mist
  • Notes: Top / Middle / Base (e.g., Bergamot / Rose / Sandalwood)
  • Volume: 30ml / 50ml / 75ml / 100ml / 200ml (separate SKUs)
  • Gender target: Men / Women / Unisex
  • Season: Spring / Summer / Autumn / Winter / Year-round
  • Occasion: Casual / Work / Evening / Special
  • Brand: Parfumier name / house
2
UCP Manifest & Search Endpoint MEDIUM EFFORT
examples/demo_common/ucp.py — add new filter params + update product schema
Current search params
  • q — text search
  • category — electronics category
  • min_price / max_price
  • in_stock
  • limit
Fragrance search params (add these)
  • q, min_price, max_price, in_stock, limit — unchanged
  • scent_family — Floral / Woody / Citrus …
  • concentration — EDT / EDP / Parfum
  • gender — Men / Women / Unisex
  • volume_ml — 30 / 50 / 100 / 200
  • notes — comma-separated scent notes
  • occasion — casual / evening / work
Also update product schema returned by GET /ucp/products: add notes, concentration, volume_ml, scent_family, gender_target to each product object. The UCP manifest's capabilities.product_discovery.features[] list drives what _build_tools() exposes to Gemini — add the new filter names there.
3
Gemini Agent — System Prompt & Tools LOW EFFORT
examples/demo_common/gemini_ucp_agent.py — prompt auto-generated from manifest; tools auto-built
System prompt today (generated from manifest)
  • "You are a shopping assistant for ACME Electronics."
  • Understands laptop specs, RAM, processor queries
  • Tools: search_products(q, category, min_price, max_price)
After updating manifest agent_hints
  • "You are a fragrance advisor for ACME Parfums…"
  • Understands scent families, concentrations, pairing suggestions
  • Asks clarifying questions: "Do you prefer floral or woody?"
  • Tools: search_products(q, scent_family, concentration, gender, …) — auto-expanded from manifest
  • Recommends complementary scents, layering tips
Only change needed: update business.name, business.description, and agent_hints in build_ucp_manifest() in ucp.py. The _system_prompt() and _build_tools() methods auto-derive everything from the manifest — no code changes in the agent.
4
FastAPI Server + TrackedAgent NO CHANGE
scripts/gemini_web_server.py — domain-neutral; serves whatever the UCP layer returns
The FastAPI server, TrackedAgent, cart tracking, and all API endpoints (/api/chat, /api/cart, /api/reset) require zero changes. They are product-category-agnostic. The agentic loop, FunctionCall routing, and cart_additions tracking work identically for fragrances.
5
React Frontend → Google Shopper REPLACED
examples/gemini-storefront/ replaced by Google Merchant Center + Google Shopping UI
React SPA (removed)
  • Custom product grid cards
  • Cart sidebar (useState)
  • Manual filter UI
  • Custom checkout PO flow
  • LoginScreen + sessionStorage auth
Google Shopper provides out-of-box
  • Product listing with rich images, reviews, ratings
  • Filter UI: brand, price, fragrance family, gender
  • Google Pay / saved cards checkout
  • Product comparison, wishlist
  • Mobile-optimised, accessible by default
  • Price drop alerts, stock notifications
Gemini chat widget survives — embed it as a floating assistant inside the Google Shopping page via an iframe or web component. It handles conversational queries ("Find something woody and sophisticated for evenings") while Google Shopper handles standard browse/filter/buy.

Google Shopper Out-of-Box — What It Gives You vs What You Still Build

✅ Google Shopper provides (no code needed)
  • Product listing page with images, prices, ratings
  • Search bar with fragrance-specific filters (once GMC attributes set up)
  • Mobile UI, dark mode, accessibility
  • Google Pay, saved addresses, 1-click checkout
  • Customer reviews & Q&A (Google's moderation)
  • Price comparison with other sellers
  • Structured product data (schema.org) for SEO
  • Buy on Google fulfilment
  • Shopping ads (paid) + free listings
🔧 You still build / configure
  • Google Merchant Center account — register your store, verify domain
  • Product feed — Salesforce B2B → GMC sync (inventory, prices, images in real-time). Use GMC API or a middleware like Feedonomics
  • Fragrance-specific GMC attributes: google_product_category = "Health & Beauty > Fragrances", gender, scent, item_group_id per fragrance (groups volume variants)
  • Gemini chat widget — embed as floating assistant alongside Google Shopper. Handles: "recommend a gift for my wife who likes florals"
  • B2B checkout path — Google Shopper handles B2C. For B2B (PO numbers, account pricing), still needs your UCP / Salesforce flow
  • Inventory webhook — Salesforce stock changes → GMC feed update (prevent selling out-of-stock)

Migration Steps — In Order

1
Create fragrance product schema in Salesforce B2B
Add custom fields to Product2: Scent_Family__c, Concentration__c, Top_Notes__c, Middle_Notes__c, Base_Notes__c, Volume_ML__c, Gender_Target__c. Create new product categories under B2B catalog.
2
Import fragrance product catalog into Salesforce
Load products via Data Loader or Bulk API. Each fragrance needs SKUs per volume (30ml, 50ml, 100ml). Set up PricebookEntry per volume. Upload product images to CMS.
3
Update UCP manifest in ucp.py
Change business.name → "ACME Parfums", business.description → fragrance store description, agent_hints → fragrance advisor persona. Add "scent_family_filter", "concentration_filter", "gender_filter" to capabilities.product_discovery.features[].
4
Add new query params to GET /ucp/products
Add scent_family, concentration, gender, volume_ml, notes as optional FastAPI query params. Update the filter logic to read new Salesforce custom fields. Update product response schema to include these fields.
5
Set up Google Merchant Center account
Create GMC account, verify domain, agree to Google Shopping policies. Set up product feed: google_product_category = 2388 (Fragrances). Required attributes: id, title, description, link, image_link, price, brand, gtin, gender, scent. Group volume variants with item_group_id.
6
Build Salesforce → GMC product feed sync
Options: (a) scheduled export from Salesforce → GMC Content API; (b) middleware like Feedonomics or GoDataFeed; (c) Salesforce Commerce Cloud connector if on SFCC. Sync must propagate price changes and stock changes within 30 mins to avoid GMC penalties.
7
Embed Gemini chat widget alongside Google Shopper
The FastAPI server + Gemini agent stays on Railway unchanged. Embed as a floating chat button on your store landing page using an iframe pointing to the Railway URL. Wire the iframe so clicking a Gemini-recommended product deep-links into the Google Shopper product page.
8
Test & validate end-to-end
Smoke test: "Find a woody EDP for men under $80" → Gemini should call search_products(scent_family="woody", concentration="EDP", gender="men", max_price=80) → UCP queries Salesforce → returns fragrance products. Confirm GMC feed shows correct prices and inventory. Place a test order through both paths (Gemini → UCP → Salesforce, and Google Pay checkout).
