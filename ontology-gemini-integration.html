3 Integration Points

1
Startup — System Prompt
once per server boot
Ontology key facts are injected into the UCP manifest's agent_hints field.

build_ucp_manifest() reads from ontology store and adds:

"heavy work = RAM >= 16GB, processor i7/i9. notebook = laptop = ultrabook. category: Gaming > Workstation > Business"

Gemini reads this before every conversation — no runtime lookup needed for common terms.
2
Query Time — Term Enrichment
per user message
Before Gemini's tool args reach GET /ucp/products, a middleware layer queries the ontology to expand terms.

User says: "gaming machine"
Ontology returns: category=Gaming, RAM>=16GB, GPU=required

Gemini's FunctionCall args are enriched before the UCP HTTP call is made — Salesforce receives clean structured filters.
3
Result Time — Product Enrichment
per product returned
After Salesforce returns products, ontology enriches each product with related concepts before Gemini generates the reply.

Product: HP ProBook 440
Ontology adds: related_to=[EliteBook, ZBook], good_for=[business travel, remote work], accessories=[USB-C dock, ProBook sleeve]

Gemini uses this to give smarter recommendations and cross-sell suggestions.

Full Query Trace — "I need a laptop for heavy work under $1,500"

1
User → React Frontend
Types natural language message
"I need a laptop for heavy work under $1,500"
2
FastAPI → Gemini
Sends message to Gemini with system prompt that includes ontology hints injected at startup
system_prompt includes: "heavy work = RAM >= 16GB, processor i7/i9/Ryzen9 laptop = notebook = ultrabook categories: Workstation > Gaming > Business"
3
Gemini Model
Uses ontology facts from system prompt to understand "heavy work". Generates FunctionCall:
FunctionCall: search_products query = "laptop workstation" category = "Workstation" max_price = 1500
4
Ontology Layer — Query Enrichment (Point 2)
Before calling UCP, _call_ucp() runs args through ontology enricher on GCP:
Input: { query:"laptop workstation", category:"Workstation", max_price:1500 } Ontology lookup: "workstation" → min_ram=16, processor_tier="i7|i9|Ryzen9" "Workstation" category → also include "Gaming" category Output: { query:"laptop", category:["Workstation","Gaming"], max_price:1500, min_ram:16, processor_keywords:["i7","i9","Ryzen 9"] }
5
UCP Endpoint → Salesforce
Enriched params reach Salesforce as structured SOQL — no guesswork
SELECT Id, Name, UnitPrice FROM ProductCatalog WHERE UnitPrice < 1500 AND Category__c IN ('Workstation','Gaming') AND RAM_GB__c >= 16 AND Processor__c LIKE '%i7%' OR '%i9%' OR '%Ryzen 9%'
6
Ontology Layer — Result Enrichment (Point 3)
Products returned from Salesforce are enriched before Gemini generates the reply:
HP ZBook Fury G10 — $1,449 + good_for: ["3D rendering", "data science", "video editing"] + related: ["HP ZBook Studio", "Dell Precision 3580"] + accessories: ["HP Thunderbolt dock", "extended warranty"]
7
Gemini → User
Generates a rich, context-aware reply using both Salesforce data and ontology enrichment
"For heavy work under $1,500, the HP ZBook Fury G10 ($1,449) is your best match — it has an Intel i9, 32GB RAM, and is built for 3D rendering and data science. You might also consider pairing it with an HP Thunderbolt dock."

What Ontology Data Looks Like

Synonyms (WordNet / custom)
laptop→notebook, ultrabook, portable computer
heavy work→workstation, high performance, RAM ≥ 16GB
gaming machine→gaming laptop, GPU required, high refresh
fragrance (future)→perfume, cologne, scent, eau de toilette
woody (future)→scent_family: Cedarwood, Sandalwood, Oud
Category Hierarchy (Google Product Taxonomy)
Electronics→Computers > Laptops > Workstations
Workstation→min_ram=16, processor_tier=i7+
Gaming→GPU required, refresh_rate ≥ 120Hz
Business→weight < 1.8kg, battery > 10h
Health & Beauty→Fragrances > EDP / EDT / Parfum
Attribute Rules (Schema.org/Product)
RAM→type: integer, unit: GB, values: 8/16/32/64
Processor→brand: Intel/AMD, tier: i5<i7<i9
Storage→type: SSD/HDD, unit: GB/TB
Price→currency: USD, unit: per item or per volume
Relationships (GoodRelations)
HP ZBook→compatible_with: HP Thunderbolt Dock
Workstation→often_bought_with: external monitor, dock
Gaming Laptop→related_to: gaming mouse, gaming headset
Brand: HP→product_lines: ProBook, EliteBook, ZBook
